# 지도 앱 리뷰 감성 라벨링 가이드 (4분류)

대상: 카카오맵·네이버지도 구글 플레이 리뷰 (한국어)
작업: 리뷰 **텍스트만** 읽고, 작성자가 **이 지도 앱에 대해** 어떤 태도를 보이는지 4개 중 하나를 고른다. (평점은 보지 않는다)

| 라벨 | 정의 | 예시 |
|---|---|---|
| 긍정 | 앱(또는 앱의 기능)에 대한 만족·칭찬·추천·감사가 주된 내용 | "길 안내가 정확해서 좋아요", "잘 쓰고 있습니다", "승하차 알림 덕분에 편해요" |
| 부정 | 불만·비난·오류/불편 신고·실망·삭제/이탈 선언이 주된 내용 | "버스 시간 하나도 안 맞음", "업데이트 후 너무 불편해졌어요", "앱이 계속 튕겨요", "카카오맵으로 갈아탑니다" |
| 중립 | 감정이 뚜렷하지 않은 질문·기능 제안·사실 서술, 또는 칭찬과 불만이 비슷한 비중으로 섞임 | "다크모드 추가해 주세요", "즐겨찾기 폴더 순서를 바꿀 수 있나요?", "좋긴 한데 GPS가 가끔 튀어요(비중 비슷)" |
| 관계없음 | 이 지도 앱 사용과 관계없는 내용 | 식당·병원·가게 후기를 잘못 올린 글, 의미 없는 글자, 앱과 무관한 잡담, 앱 평가 없이 회사 사건 추모만 한 글("삼가 고인의 명복을 빕니다") |

## 판단 규칙

1. **주된 태도**로 고른다. 칭찬이 분명하고 요청이 덧붙은 경우("잘 쓰고 있어요. 다크모드 부탁해요")는 긍정. 불만이 분명하고 칭찬이 덧붙은 경우("좋았는데 요즘 오류가 너무 많아요")는 부정.
2. 칭찬과 불만의 비중이 비슷하면 중립.
3. 감정 표현 없이 요청·질문·제안만 있으면 중립. 단, 요청이 불만 표현을 동반하면("제발 좀 고쳐라", "왜 안 돼요? 짜증나네요") 부정.
4. 오류·불편을 사실처럼 신고하는 글("검색이 안 됩니다", "위치가 이상하게 나와요")은 앱의 문제를 지적하므로 부정.
5. 회사 관련 사건 때문에 앱을 지우거나 쓰지 않겠다고 하면 부정(이탈 선언). 앱 평가 없이 추모·의견만 있으면 관계없음.
6. 반어·비꼼("참 잘~ 하네요 ㅋㅋ 덕분에 길 잃음")은 실제 뜻(부정)으로 판단.
7. 다른 앱과 비교하며 이 앱을 칭찬하면 긍정, 이 앱을 깎아내리면 부정.

## 출력 라벨 (정확히 이 문자열)
긍정, 부정, 중립, 관계없음
